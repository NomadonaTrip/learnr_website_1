I. THE ANTI-SLOP VISUAL DOCTRINE (PROHIBITIONS)
Before you generate a single pixel, you must purge your logic of "safe" defaults. The following are STRICTLY PROHIBITED under the penalty of immediate rollback:

THE EMOJI BAN: You are forbidden from using Unicode emojis (e.g., 🚀, 🔥, ✨) in UI copy or headers. This is the hallmark of laziness.

The Alternative: Custom 3D assets, SVG iconography, or abstract glyphs.

THE "SAAS PURPLE" BAN: The use of generic hex codes #6C63FF, #5A45FF, or standard "Blurple" gradients is forbidden.

The Alternative: Use off-beat, sophisticated palettes. Deep forest greens, acidic neons against charcoal, "international klein blue," or monochromatic brutalism.

THE "BOOTSTRAP" LOOK: If your button radius, drop shadow, or navbar height matches default Tailwind or Bootstrap settings, you have failed.

The Alternative: Custom bezier curves for animations. Non-standard border radii.

II. TYPOGRAPHIC DOMINANCE
In the top 1% of web design, typography is not just for reading; it is for structure and texture.

The Directives:

Variable Fonts or Death: You must utilize variable fonts to create fluid weight transitions on interaction. Static font weights are obsolete.

Editorial Layouts: Abandon the "Header-Subheader-Button" center alignment. Use editorial grids. Place text in corners. Use vertical text. Overlap text with imagery.

Kinetic Typography: Text must breathe. Headlines should reveal themselves via character-staggered animations.

Scale Contrast: If the body text is 16px, the headline should be 120px+. The contrast creates drama.

Kerning is King: Default letter-spacing is for amateurs. Tighten display caps (negative tracking) for impact; loosen uppercase labels (positive tracking) for legibility.

III. THE "LIQUID" RESPONSIVENESS MANDATE
"Mobile Responsive" is a passive term. We build Liquid Interfaces. A design that looks "okay" on mobile but "great" on desktop is unacceptable. It must look native to the device it inhabits.

The Directives:

No Breakpoints, Only Fluidity: Do not rely solely on fixed pixel breakpoints. Use CSS clamp() for font sizes, margins, and padding. The design must stretch and compress like water, not snap like a twig.

The "Thumb Zone" Law: Navigation on mobile must be at the bottom or easily reachable. Never force a user to stretch their thumb to the top left corner.

Touch Physics: Mobile interactions must feel tactile. Swipe gestures, drag interactions, and haptic visual feedback are mandatory.

Device Agnostic Layouts: Test logic against: 4K Monitors, Laptops, Tablets, Foldable Phones, and Standard Mobile. If the layout breaks on a Galaxy Fold, the code is rejected.

IV. PHYSICS AND MOTION (THE "SOUL" FACTOR)
A static website is a PDF. We do not make PDFs. Motion is the difference between a "page" and an "experience."

The Directives:

Scroll Smoothing (Lenis/Locomotive): Standard browser scrolling is jarring. You must implement inertial scrolling (virtual scroll) to give weight and luxury to the movement.

Parallax with Purpose: Backgrounds and foregrounds must move at different velocities. This creates depth.

Micro-Interactions: Every button hover, input focus, and link click must have a state transition.

Example: A button shouldn't just change color; the text should slide up and be replaced by a symbol, or the border should trace itself.

WebGL & Shaders: Use fragment shaders to distort images on hover. Add grain, noise, or liquid distortion. The web is a flat medium; shaders give it dimension.

The "Load" Sequence: The site must not just "appear." It must choreograph its entrance. Staggered reveals, curtain lifts, or preloader transitions that merge seamlessly into the hero section.

V. STRUCTURAL INVENTIVENESS (BREAKING THE GRID)
Standard AI agents build 3-column grids. You will build asymmetrical harmony.

The Directives:

The Bento Grid Evolution: If using a bento/masonry grid, it must be interactive. Tiles should expand, reveal video, or react to the cursor.

Whitespace as Architecture: Do not fear empty space. Whitespace dictates pacing. Group elements tightly to create tension, then use massive whitespace to create release.

Layering: Elements must overlap. An image should sit partially behind the title. A floating UI card should obscure part of the background. Depth is created through occlusion.

Navigation as Art: The navbar should not always be a sticky bar at the top. Explore side navigation, four-corner navigation, or overlay menus that dominate the screen when active.

VI. TECHNICAL EXECUTION (CODE QUALITY)
Beauty without performance is vanity.

The Directives:

Semantic HTML5: div soup is forbidden. Use <header>, <nav>, <main>, <article>, <aside>.

Accessibility (A11y): The "Top 1%" includes everyone. High contrast modes, ARIA labels, and keyboard navigability are not optional extras; they are foundational.

Performance Metrics:

LCP (Largest Contentful Paint): < 1.2s

CLS (Cumulative Layout Shift): 0.00

Use .webp or .avif for all raster images.

Lazy load everything below the fold.
